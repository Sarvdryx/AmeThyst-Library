# Synchronization Service Contract

This contract defines the function signatures, parameters, and behaviors for synchronization services interfacing PostgreSQL and Memgraph.

---

## 1. Wishlist Sync Service

### `syncWishlistToMemgraph(userId, bookId, action, addedAt)`
Handles real-time additions or removals of items to/from user wishlists.

- **Parameters**:
  - `userId` (String, Required): UUID of the user.
  - `bookId` (String, Required): ID of the book.
  - `action` (String, Required): Either `'ADD'` or `'REMOVE'`.
  - `addedAt` (Date/String, Optional): Timestamp of creation. Defaults to current time for `'ADD'`.

- **Behavior**:
  - If `action` is `'ADD'`:
    1. Checks/creates User and Book nodes using `MERGE` to avoid orphans.
    2. Runs Cypher query to establish `[:WISHLISTED]` edge.
  - If `action` is `'REMOVE'`:
    1. Runs Cypher query to locate and delete (`DETACH DELETE` or simple edge deletion) the `[:WISHLISTED]` relationship.
  - Failures must catch errors and log them, never throwing to block the main thread.

## 2. Recommendations Sync Service

### `syncRecommendationToMemgraph(recommendation)`
Synchronizes recommendation logs generated by the system or updated by user clicks.

- **Parameters**:
  - `recommendation` (Object, Required):
    - `user_id` (String, Required): UUID of the user.
    - `book_id` (String, Required): ID of the book.
    - `showed_at` (Date/String, Required): Timestamp when recommended.
    - `is_clicked` (Boolean, Required): Whether it has been clicked.
    - `renewed_at` (Date/String, Optional): Timestamp of update/click.

- **Behavior**:
  - Merges `User` and `Book` placeholder nodes if missing.
  - Runs Cypher:
    ```cypher
    MATCH (u:User { id: $userId })
    MATCH (b:Book { id: $bookId })
    MERGE (u)-[r:RECOMMENDED]->(b)
    SET r.showed_at = $showedAt,
        r.is_clicked = $isClicked,
        r.renewed_at = $renewedAt
    ```

## 3. Search History Sync Service

### `syncSearchClickToMemgraph(userId, bookId, searchId, searchContent, createdAt)`
*(Pre-existing function under specification review for compatibility)*
Logs search query and user click.

- **Parameters**:
  - `userId` (String, Required): UUID of the user.
  - `bookId` (String, Required): ID of the book.
  - `searchId` (String, Optional): UUID of the search entry.
  - `searchContent` (String, Optional): Query text.
  - `createdAt` (Date/String, Optional): Creation timestamp.

- **Behavior**:
  - Establishes a `[:SEARCHED]` relationship containing metadata properties.
